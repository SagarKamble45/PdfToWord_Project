# PDF to Word Converter

A simple web-based PDF to Word converter built with **Python**, **Flask**, and **pdf2docx**.

The application allows users to upload a PDF file through a web interface and convert it into an editable Microsoft Word (`.docx`) document.

## Features

- Upload PDF files through a web interface
- Convert PDF documents to Word (`.docx`)
- Download the converted Word document
- Simple and easy-to-use interface
- Built with Flask
- Uses `pdf2docx` for PDF-to-Word conversion

## Tech Stack

- **Python**
- **Flask**
- **pdf2docx**
- **HTML/CSS**
